# FA/MAT API 只读测试工具

独立 Windows 测试程序，用于验证已有追溯查询接口的工位上下文与单件查询。不替换生产软件，不作拆除/清胶判定，不发送 MES 进站或完成上报，不访问本地报文库。

## 下载与运行

从本仓库 **Releases** 下载 `FaMatApiProbe-v0.1.0-win-x64.zip`，解压后双击 `FaMatApiProbe.exe`。面向 Windows 10/11 x64，自包含发布，无需另装 .NET。

公开包不含公司接口地址、真实件号、现场配置、原始指导书或响应。请在公司网络中填写你有权限使用的 HTTPS 查询服务地址（包含 `/data_query`）。不要把响应报告上传公开仓库。

## 最少操作

1. 填服务地址。按程序按钮读取产品、产线、工站和工序，选择目标项。
2. 解析工位，再**明确选中**返回的工位上下文。`linetype` 取自接口返回，不猜测 FA/SMT 类型；工位编码按完整字符串保留前导零。
3. 填起止日期，使范围覆盖已知产品的装配日期。接口截止日期是否含当天尚待现场确认；必要时显式扩大一天，并记录实际范围。
4. 选择一个测试接口，填对应的完整 PCBA DMC、FA ID 或物料 ID，点击查询。B 元件/过站查询输入 **FA ID**，PCBA 反查输入 **PCBA DMC**，两者不能混用。
5. 查看原始请求、响应、结果行、HTTP 状态、业务状态与耗时。程序保存本机诊断报告；把相关报告私下带回分析即可。

不同 FA 候选不会自动选第一条，也不会自动转查其他接口。空结果仅说明**本次产品/工位类型/日期/接口条件下**未命中，不等于产品无绑定；查询耗时不等于数据库执行耗时。

## 请求约束

工位解析用于取得本次产品上下文与 `linetype`。本版七种单件查询仅发送 `pt`、`linetype`、起止日期和对应完整码，**不额外发送工位、产线或工序过滤**；不要把界面显示的工位当作查询范围限制。

- 仅调用固定允许列表中的追溯查询接口；接口虽使用 HTTP POST，其业务用途为读取。
- 单次手工操作，全 HTTP 串行，无压力循环、无自动重试，无启动联网。
- HTTPS，系统证书校验，禁代理、禁重定向；取消和总超时覆盖请求及响应读取。
- 业务 `status:nok`、HTTP 错误、结构错误、响应超限与合法 `data:null` 分开显示。
- 输入或上下文改变后，旧解析资格失效，需重新解析/选择；不凭旧状态继续查询。
- 原始响应可能含产品与 SQL 信息，报告仅本机保存，不自动上传，不承诺无限历史空间。

## 验证边界

交付仅验证本地合成响应下的基本功能、界面与自包含运行包；未连接公司内网，未证明目标线实际命中、时间字段口径或查询速度。未做压力、长期稳定性或现场 MES 验收。它是诊断试用工具，不是生产放行软件。

`--self-test` 为离线合成自检，不访问公司服务。
